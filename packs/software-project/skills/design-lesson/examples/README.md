# Design examples

Annotated worked examples for the design track (`/design-lesson`). They describe **thumbgen**, a small
command-line tool that generates thumbnails for a folder of images — deliberately unrelated to your own project,
so you learn the technique here and still write your own project docs from scratch.

| File | Teaches | Lessons |
|---|---|---|
| `01-requirements.md` | Weak vs good requirements, IDs, acceptance criteria, NFRs, non-goals | D2, D3 |
| `02-architecture.md` | Modules, dependency rules, Mermaid graph + sequence diagrams | D4, D5 |
| `03-module-design.md` | Header-first API, ownership, performance notes, test plan | D7, D9, D6 |
| `04-adr.md` | Decision record with real options and trade-offs | D1, D8 |

Annotations look like this:

> 💡 **Why:** explanation of a choice in the example.
