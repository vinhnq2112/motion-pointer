# /quiz [n]

Default n = 5. Ask **one question at a time**; wait for each answer.

## Selection
- ~50% from `learning/weak-spots.md` (lowest score / oldest first)
- ~30% from topics completed 1–4 weeks ago (`learning/progress.md`, `learning/journal/`)
- ~20% from the current topic
- Use Q&A and Pitfalls entries in `learning/knowledge/` as a source — the learner's own past questions are the
  best material.

## Question types
Use the types listed in `subject.md` → "Quiz question types". Mix them; prefer applying over reciting.

## After each answer
Correct / partial / wrong → short correct explanation → next question.

## At the end
Score summary. Update `learning/weak-spots.md` (adjust scores, remove entries with two consecutive 4+,
add new gaps). Suggest the next step.
