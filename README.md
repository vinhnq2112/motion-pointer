# motion-pointer — Gyro + accelerometer cho remote điều khiển con trỏ

Khoá học 7 ngày (sprint mode) với mentor Claude Code: học gyro và accelerometer bằng C++, để một remote có IMU
điều khiển con trỏ trên menu TV. Không cần thiết bị thật: simulator 3D `tools/imu-sim/` tạo dữ liệu cảm biến.
Kết quả cuối khoá: bản demo trong simulator và bài thuyết trình PowerPoint tiếng Anh 60 phút về drift và cách xử lý.
